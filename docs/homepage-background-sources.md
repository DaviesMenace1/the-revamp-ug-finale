# Homepage Background Photography Sources

The homepage uses real photography hosted by Unsplash, not generated imagery. The source collection reviewed was [Unsplash Interior Architecture](https://unsplash.com/s/photos/interior-architecture), which exposes the selected image URLs and links to their individual photo pages.

The public Unsplash search page describes the collection as free interior architecture imagery, but the individual photo pages remain the authoritative source for each image’s current license and attribution details. The site keeps text in the semantic foreground layer and uses `bg-canvas/75 dark:bg-obsidian/80` plus a gradient, preventing the photograph from reducing contrast in either theme.
